# Генетические алгоритмы, лабораторные 1 и 2

Лабораторная 1 ищет минимум функции Discus. Общий код алгоритма лежит в `common/ga.py`, чтобы вторая лабораторная могла его переиспользовать. Текст второй лабораторной пока не задан, заготовка в `lab02/`.

## Установка

Нужен Python 3.12.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Проверка, что функция в нуле равна нулю и один и тот же seed даёт один и тот же ответ:

```bash
python lab01/check.py
```

Один прогон конфигурации с популяцией 40. Seed берутся из JSON, по умолчанию это 1…20.

```bash
python lab01/run.py --config lab01/config_base.json
```

Все опыты для отчёта: популяция 40, популяция 120 и случайный поиск при тех же 6000 вызовах функции.

```bash
python lab01/run.py --all
python lab01/plot.py
```

Результаты пишутся в `lab01/results/`: таблицы `runs.csv` и `history.csv`, графики `ga_pop40.png`, `ga_pop120.png`, `ga_vs_random.png`. Отчёт: `lab01/report.md`.

Параметры варианта в этой работе: N = 3, Q = 0, Y = 26, V = 18, размерность d = 5.
